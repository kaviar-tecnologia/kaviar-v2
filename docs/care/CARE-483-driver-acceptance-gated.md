# CARE-483 — Driver acceptance gated

## Estado

Este controle registra que o aceite do motorista para CARE permanece fechado por padrão.

## Garantias

- CARE é bloqueado antes de aceitar oferta.
- CARE é bloqueado antes de atribuir motorista à corrida.
- CARE é bloqueado antes de wallet, pricing, realtime e WhatsApp.
- A revalidação futura de elegibilidade permanece dentro da transação.
- Snapshot elegível sozinho não libera uma corrida CARE real.

## Fora de escopo

Este passo não habilita CARE oficial, não muda dispatcher, não muda pricing, não muda wallet, não cria migration e não faz deploy.
